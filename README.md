# Multiply Club for Vercel

This is the fixed, static version of Multiply Club. It needs no build step or server-side services.

## Deploy with Vercel CLI

1. Extract this ZIP file.
2. Open a terminal in the `Multiply-Club-Vercel` folder.
3. Run `npx vercel` and follow the prompts to sign in and create or link a Vercel project.
4. To publish the production deployment, run `npx vercel --prod`.

The game saves badges and practice progress in the browser on the device that plays it. Progress does not sync between devices.
